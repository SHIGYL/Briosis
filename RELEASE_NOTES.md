# Briosis v0.1.0.4

Brio stable-base update

- Updated Briosis to the Brio 0.8.0.12 stable codebase.
- Integrated the latest upstream fixes for input handling, actor spawning and appearance, VFX, camera tools, overlays, and related GPose systems.
- Added upstream relative-position support for Camera and Light presets while preserving compatibility with existing presets.
- Integrated the latest MCDF/STG loading and temporary-file handling fixes.
- Fixed misleading error-level log spam during successful MCDF cache generation.
- Preserved Briosis Facial Controls, Facial Presets, Tongue Tool, Tongue Profiles, Undo/Redo, Briosis IPC namespace, Web API separation, and Brio/Briosis GPose conflict protection.
